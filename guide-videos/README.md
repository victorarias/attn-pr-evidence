# Guide videos: previews

The four guide clips in the approved look, as animated AVIFs embedded the way
the guide embeds them (`![alt](clip.avif)`). They get recorded again after the
sidebar's chief setup card is redesigned, since every clip shows the sidebar.

## new-agent (getting-started, Start an agent)

![Cmd+N (Ctrl+Shift+N on Linux) opens the new agent picker. Enter picks the recipes repository, the arrow keys pick its fix-unit-conversion worktree, and a new Claude Code agent opens beside the one on screen.](new-agent.avif)

## split-terminals (desktops, Tiles)

![Cmd+D (Ctrl+Shift+D on Linux) opens a shell beside a Claude Code agent, and you run the tests in it. Cmd+Shift+D (Ctrl+Alt+D on Linux) then opens another shell below it.](split-terminals.avif)

## move-tiles (desktops, Moving agents)

![You drag a tile onto desktop 2 in the sidebar and land there with it. Cmd+Option+1 (Ctrl+Alt+1 on Linux) then moves it back to desktop 1 and takes you with it.](move-tiles.avif)

## queue-on (queue, Turning it on)

![Cmd+Shift+K (Ctrl+Alt+K on Linux) opens the command palette and you run "Turn on the agent queue". The sidebar then lists the two agents waiting for you first, oldest on top, and the working one below them.](queue-on.avif)
