# attn-pr-evidence

Screen recordings referenced from [attn](https://github.com/victorarias/attn)
PR descriptions as evidence of testing. Written by
`scripts/pr-evidence.sh publish` in the attn repo: one directory per branch,
each clip as a full-quality `.mp4` beside the `.gif` that GitHub embeds
inline (GitHub never inline-plays a repo-hosted mp4 — receipts in #1).
PR descriptions pin raw URLs to the pushed commit sha, so files here are
never moved or rewritten.
